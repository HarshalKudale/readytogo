# Areas

Each area is a slice of the checklist. Work only the area you were asked for: read its file, run `readytogo analyze --area <slug>`, and ignore the rest.

- [`brand`](areas/brand.md): Name, logo, icon master, favicon, tagline (7 items)
- [`domain`](areas/domain.md): Domain, HTTPS, DNS records, email deliverability (15 items)
- [`legal`](areas/legal.md): Privacy policy, terms, consent, regional law, payments and tax (20 items)
- [`packaging`](areas/packaging.md): Source maps, minification, bundle size, images, dependencies, installers, release hygiene (33 items)
- [`quality`](areas/quality.md): CI, tests, crash reporting, analytics, uptime (18 items)
- [`seo`](areas/seo.md): Titles, meta, Open Graph, sitemap, structured data, broken links, backlinks (11 items)
- [`docs`](areas/docs.md): README, quickstart, API reference, env docs, security policy, support (8 items)
- [`assets`](areas/assets.md): Icons, screenshots, promo art, 2D and 3D mockups, demo video (5 items)
- [`stores`](areas/stores.md): App Store, Google Play, extension stores, Microsoft Store, desktop signing, registries (40 items)
- [`launch`](areas/launch.md): Launch sites, communities, reviews, backlinks, second wave (23 items)
